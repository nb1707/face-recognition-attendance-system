# Curated experimental results

This directory contains privacy-reviewed aggregate evidence copied or transcribed from existing local experimental outputs. Original outputs remain unchanged under ignored `backend/storage/` paths.

## Privacy treatment

The curated files exclude raw images, videos, embeddings, gallery mappings, student names/identifiers, camera addresses, absolute machine paths and per-observation records. Generic experimental conditions are retained only where needed to interpret denominators and limitations.

## Inventory

| Directory | Evidence |
|---|---|
| `phase71/` | Static offline full-frame versus desktop-tiled comparison |
| `phase8a/` | Unlabelled diagnostic replay funnel and timing |
| `phase8b1/` | Offline quality-threshold sweep aggregate |
| `phase8b2/` | Labelled spatial/distance aggregate and candidate comparison |
| `phase8b3/` | Seven-sequence controlled replay through Gate B |

These are development results, not production calibration or general accuracy claims. Each summary states its own denominator and methodological boundary.
